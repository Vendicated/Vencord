# BetterScreenShare

A clean, standalone Vencord plugin that unlocks Nitro stream qualities and boosts screenshare performance.

## Features

- **Quality Unlock**: Stream in 1080p, 1440p (2K), 4K, and Source resolution without Nitro.
- **60 FPS Everywhere**: Stream in 60 FPS in any voice channel, DM, or unboosted server.
- **Custom Bitrate**: Max bitrate up to 24 Mbps (default 12 Mbps) to eliminate pixelation in games.
- **In-Stream Settings Menu**: Right-click on any stream to quickly change bitrate, audio, and visual settings on the fly.
- **Stereo Audio**: Stream true dual-channel stereo audio with DTX disabled.
- **Crisp Text Scaling**: Optimizes contrast scaling so shared IDEs, code, and text windows look razor-sharp.
