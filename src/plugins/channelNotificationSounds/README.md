# ChannelNotificationSounds

Assign distinct notification sounds to specific channels, direct messages, groups, and servers.

## Features

- **Context Menu Integration**: Right-click any channel, DM, group chat, or server icon to quickly choose or clear a sound.
- **Multiple Tone Presets**: Built-in harmonic synthesizer presets (Alarm, Chime, Critical, Doorbell, Radar, Soft) that do not require external audio files.
- **Custom Audio Support**: Option to use custom sound effects via HTTPS audio URLs.
- **Flexible Trigger Modes**:
  - *Only when Discord would notify* (default): respects native mutes, channel focus, and mention settings.
  - *On all incoming messages*: triggers sound on every new message in the selected target.
- **Natural Throttling & Deduplication**: Prevents audio overlapping or double-playing on rapid message bursts.
