# EditUsers

Customize how any user appears in your Discord client. All changes are local and only visible to you.

Right-click a user or open the three-dot menu on their profile and select **Edit User** to customize them.

## Features

- **Display Name:** Set a custom display name and username colour, with an option to override server role colours. You can also hide server nicknames or prefer them over your custom name.
- **Avatar:** Set a custom avatar from a local image or URL, or use Discord's default avatar. You can also hide server avatars or prefer them over your override.
- **Banner:** Set a custom profile banner from a local image or URL, or pick a custom banner colour. You can also hide server banners or prefer them over your override.
- **Profile:** Set custom pronouns, change or hide message tags (App, Official, Server, or Original Poster), and apply cosmetics (avatar decoration, profile effect, nameplate, and profile frame) from a Discord Shop share link or by copying them from another user.
- **Image Backups:** Export and import your local avatar and banner images in the plugin settings.
