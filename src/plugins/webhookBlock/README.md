# Webhook Block

Adds an option to block webhooks like a normal user.

It then shows webhook as a blocked user like any other. You can join it with **NoBlockedMessages** to hide the webhook completely.

## Use

It's mainly useful for people who are active on servers using various bridges (like recently very popular Fluxer to Discord bridge)

It may find use for other users too if you find some webhooks annoying.

## Limitations

Currently the plugin shows the "Block Webhook" button only when you're right clicking the message due to limitation what info Discord passes through context menu.
