# KaomojiPicker (๑>ᴗ<๑)

Adds a Kaomoji Tab to bring back the removed Kaomoji experiments

### Small tips
You can quickly open the Kaomoji Tab by pressing `Ctrl + E` followed by `Ctrl + F`.
