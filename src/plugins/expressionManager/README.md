# ExpressionManager

Adds many management options for expressions (emojis and stickers)

- **Cloning:** Copy expressions to your own Server
- **Quick Management:** Quickly edit or delete expressions via the expression picker context menu
- **Remove from Frequently used:** Reaction bombed a message and now your frequently used list is cluttered? Just remove undesired entries
