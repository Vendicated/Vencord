# RenameGifs

![RenameGifs example](./exampleGIF.gif)

Rename favorited GIFs, search by name, see names on hover.

## Usage

Right-click a favorited GIF → **Rename Favorite** → type a name, **Apply**. Blank + Apply clears it. Hover a named favorite to see its label; search the picker by name.

## Backup (optional, desktop only)

Set **Backup folder path** in settings to an existing empty folder. Backs up automatically on change. Buttons: **Save backup now**, **Load backup now**, **Reset all names**. File: `renamedGifsBackup.json`.

## Notes

CDN/media host variants and share-link providers (e.g. Klipy) are matched to the same favorite.
