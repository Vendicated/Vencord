# BetterMedia

Brings the mobile app's Media / Files / Links / Pins gallery to desktop.

Discord's mobile app lets you open any DM or channel's profile and filter everything that was
ever sent in it by images & videos, files, links, or pinned messages. Without endlessly scrolling
through chat history. Desktop never got this (kinda). BetterMedia adds it: click the gallery icon
next to the message box to open a searchable overview of the current channel with the same four
tabs:

- **Media** - every image/video/GIF ever posted, click to open Discord's normal image
  viewer with full gallery navigation
- **Files** - every attached file, with size, sender, and a one click download/open
- **Links** - every link that was ever shared, with its preview thumbnail
- **Pins** - all pinned messages, rendered like normal chat messages

Every row/tile has a "Jump to message" button that takes you straight to that message in the chat.

Works in DMs, group DMs, and server channels.
